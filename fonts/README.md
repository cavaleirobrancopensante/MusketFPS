# Fonts

The only files in the game that aren't made in code. Both are free fonts
under the SIL Open Font License (see the OFL files here):

- **IM Fell English SC** and **IM Fell English Italic** (Igino Marini, after
  the Fell types of the 1670s): titles and headings. Old printers' type, the
  look of a regimental order book.
- **Alegreya Sans** (Huerta Tipográfica): everything else. A humanist sans
  that stays readable at small sizes on a phone.

`scripts/ui.gd` loads them and builds the game's theme.
